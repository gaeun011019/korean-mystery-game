# 사건 수첩 · Korean Mystery Game

한국어로 읽고 조사하는 1인 추리 웹게임입니다. 장소의 흔적과 인물의 진술을 수첩에 모으고, 범행 인물과 핵심 근거 두 가지를 선택해 사건을 해결합니다. 계정, 제한 시간, 외부 API 없이 브라우저에서 플레이합니다.

## 다섯 사건

| 사건 | 난이도 | 추리 방식 | 목표 시간 |
| --- | --- | --- | --- |
| 그날 하지 못한 말 | 쉬움 | 펜션에서 사진과 진술의 모순 비교 | 10–15분 |
| 네 분 빠른 기록 | 보통 | 서로 다른 시계의 기록을 교정 | 15–20분 |
| 세 장의 배정표 | 어려움 | 참·거짓 조건과 출입 순서 결합 | 20–25분 |
| 마지막 장의 주인 | 보통 | 극단의 촬영 시점·출입·물증 연결 | 20–30분 |
| 빈 상자는 늦게 사라졌다 | 어려움 | 초기 가설을 반박하고 앞선 사건 재구성 | 25–40분 |

시간과 난이도는 **실제 사람의 플레이를 측정한 평균이 아닌 기획 추정**입니다. 읽는 속도, 선택적 대화, 되읽기와 힌트 사용에 따라 달라집니다. 자동 테스트 실행 시간을 플레이 시간으로 사용하지 않았습니다.

기존 세 사건은 인물 3명·단서 6개, 새 두 사건은 인물 4명·단서 8개입니다. 관계와 동기를 더 알아보는 대화가 있으며, 새 사건의 선택적 대화를 전부 읽어야 제출할 수 있는 방식은 아닙니다.

## 준비

- **Node.js 22 이상**과 JavaScript를 사용할 수 있는 브라우저가 필요합니다.
- 아래 clone 명령을 사용하려면 Git도 필요합니다. GitHub에서 ZIP을 받아 압축을 풀어도 됩니다.
- 외부 npm 패키지가 없어 **`npm install`은 필요하지 않습니다.**
- `index.html`을 더블클릭하지 말고 로컬 서버로 열어 주세요. ES 모듈을 사용합니다.

## macOS에서 실행

터미널에서:

```bash
git clone https://github.com/gaeun011019/korean-mystery-game.git
cd korean-mystery-game
node dev.mjs
```

브라우저에서 **http://127.0.0.1:4173/** 을 엽니다. 서버가 실행되는 동안 터미널을 열어 두세요. 종료는 `Ctrl+C`입니다.

## Windows에서 실행

PowerShell에서:

```powershell
git clone https://github.com/gaeun011019/korean-mystery-game.git
cd korean-mystery-game
node dev.mjs
```

브라우저에서 **http://127.0.0.1:4173/** 을 엽니다. 종료는 `Ctrl+C`입니다. ZIP으로 받았다면 압축을 푼 프로젝트 폴더에서 `node dev.mjs`를 실행하세요.

## 플레이와 저장

1. 사건 선택 화면에서 새 게임 또는 이어하기를 선택합니다.
2. 장소의 물건을 조사하고 인물에게 증거를 제시합니다. 같은 기록은 중복되지 않습니다.
3. 탐정 수첩에서 관찰한 사실과 진술을 비교합니다. 필요하면 세 단계 힌트를 요청할 수 있습니다.
4. 범행 인물과 사건에서 요구하는 근거 두 가지를 제출합니다. 필요한 조사가 남으면 안내하며, 오답 뒤에는 재조사할 수 있습니다.
5. 해결하면 사건 시간표와 각 인물이 숨긴 이유를 읽습니다.

진행은 브라우저 `localStorage`에 **사건별로 자동 저장**됩니다. 같은 기기·브라우저·프로필·사이트 주소에서 새로고침하거나 브라우저를 다시 열면 이어할 수 있습니다.

- 저장은 **origin(프로토콜·호스트·포트)** 에 묶입니다. `localhost`와 `127.0.0.1`, 4173과 44975 같은 서로 다른 포트는 저장 공간이 다릅니다. 계속 플레이할 때 같은 주소를 사용하세요.
- 시크릿 모드 종료, 사이트 데이터 삭제, 저장 차단·브라우저 정책으로 기록이 사라지거나 저장되지 않을 수 있습니다. 실패하면 화면에서 안내하고 재시도를 제공합니다.
- 손상되거나 호환되지 않는 기록은 자동으로 덮어쓰지 않습니다. 새 게임 확인 시 해당 사건만 초기화합니다.
- 여러 탭에서 같은 사건을 진행하면 마지막 저장이 우선합니다. 서버 백업, 기기 간 동기화와 저장 내보내기는 없습니다.

기본 포트가 이미 사용 중이면 기존 서버를 종료하거나 별도 포트를 지정할 수 있습니다. 포트를 바꾸면 이전 포트의 저장은 자동으로 옮겨지지 않습니다.

```bash
# macOS
PORT=44975 node dev.mjs
```

```powershell
# Windows PowerShell
$env:PORT='44975'
node dev.mjs
```

## 테스트와 빌드

macOS:

```bash
npm test
npm run build
npm run preview
```

Windows PowerShell:

```powershell
npm.cmd test
npm.cmd run build
npm.cmd run preview
```

Windows 예시는 PowerShell의 `npm.ps1` 실행 정책 문제를 피하도록 `npm.cmd`를 사용합니다. 실행 정책을 바꿀 필요가 없습니다. 기본 Node 명령으로도 검사·빌드를 실행할 수 있습니다.

```bash
node --test tests/*.test.js
node dev.mjs build
node dev.mjs preview
```

빌드는 배포용 정적 파일을 `dist/`에 만들며, `dist/`는 Git에 포함하지 않습니다. `preview`는 빌드 후 실행하며 기본 4173 포트를 사용합니다. 개발 서버와 같은 포트를 동시에 사용할 수 없으므로 먼저 개발 서버를 종료하세요. 공개 웹사이트나 GitHub Pages 설정은 이 저장소에 포함하지 않았습니다.

## 구조와 검증 범위

```text
index.html          HTML 진입점
dev.mjs             localhost 서버와 정적 빌드
src/app.js          화면과 UI 이벤트
src/game-engine.js  조사·질문·힌트·정답 규칙
src/case-data.js    첫 사건과 사건 목록
src/additional-cases.js  두 번째·세 번째 사건
src/expanded-cases.js    네 번째·다섯 번째 사건
src/save-store.js   저장 검증·복원·실패 처리
src/styles.css     화면 스타일
tests/             규칙·저장·UI 어댑터 검사
docs/DEVELOPMENT.md 개발과 테스트 안내
```

Windows / Node.js **24.19.0**에서 자동 검사 **30개**와 빌드를 확인했습니다. 기존 세 사건의 단서 순열·정답 조합 회귀, 새 사건별 384개 조사 경로·256개 제출 조합, 다섯 사건의 저장 분리·완료 복원·초기화를 검사합니다.

설치된 **Chrome 154 headless**의 별도 임시 프로필에서 새 두 사건 완주, 힌트·오답·정답·해설, 새로고침·브라우저 재실행 복원과 기존 세 사건의 테스트 저장 보존을 확인했습니다. `tests/ui.test.js` 자체는 실제 브라우저가 아닌 UI 어댑터 검사입니다. **macOS/Safari의 실제 동작과 일반 사용자의 체감 난이도·시간은 아직 검증하지 않았습니다.**

초기 버전은 읽기와 버튼 중심입니다. 음향·계정·멀티플레이·모바일 앱 패키지는 없으며, 터치 환경과 작은 화면의 전체 동선은 추가 검증이 필요합니다.
